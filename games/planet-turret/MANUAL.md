# 행성 포탑 방어전 — 선생님용 사용 설명서

교실에서 반 전체가 같은 와이파이로 접속해 **3·5·8분 동안 함께 겨루는** 방법입니다.

## 준비

1. 교사 PC를 **학생 태블릿과 같은 무선망**에 연결합니다. (업무망 랜선이면 교사 화면 위쪽에 빨간 경고가 뜹니다.)
2. `planet-turret.exe` 를 더블클릭합니다. 검은 콘솔 창이 뜨고 브라우저에 **교사 화면**이 자동으로 열립니다.
   - 콘솔 창을 닫으면 서버가 꺼집니다. 수업 중에는 최소화만 해 두세요.
   - 처음 실행할 때 Windows 방화벽 창이 뜨면 **허용**을 눌러야 학생이 접속할 수 있습니다.

## 수업 흐름

1. **QR 크게 띄우기** → 학생이 태블릿 카메라로 찍고 학번·이름을 넣어 입장합니다.
   입장한 학생은 기다리는 동안 **연습**을 합니다(점수 기록 안 됨).
2. 교사 화면에서 **3분 / 5분 / 8분** 중 하나를 고르고 **판 시작**을 누릅니다.
   모든 태블릿에서 3·2·1 카운트다운 뒤 동시에 시작합니다.
3. 진행 중에는 **실시간 순위**가 보입니다. **크게 보기**를 누르면 프로젝터용 순위판(남은 시간 + 상위 10명)이 뜹니다.
   - **잠깐 멈춤**: 모든 태블릿이 멈추고 "선생님을 봐 주세요"가 뜹니다. 남은 시간도 멈춥니다. **이어서 하기**를 누르면 3초 뒤 다시 시작합니다.
   - **지금 끝내기**: 두 번 눌러야 끝납니다(실수 방지).
4. 시간이 다 되면 학생 화면에 점수와 **우리 반 순위**, 상위 5명이 나옵니다. 결과는 자동으로 저장됩니다.
5. **이번 판 엑셀**로 결과를 내려받거나, **새 판 시작**으로 바로 한 판 더 합니다.
   **연습으로 돌아가기**를 누르면 학생들은 다시 연습 화면으로 가고, 연결이 끊긴 학생은 명단에서 정리됩니다.

## 한 판 안에서 일어나는 일

- 장소가 **북극 → 적도(동) → 서울 동쪽 → 남쪽 → 서쪽 → 북쪽** 순서로 바뀝니다.
  장소마다 시간 상한(판 시간의 80%를 6곳에 나눔: 3분이면 약 24초, 5분이면 40초, 8분이면 64초)이 있어서, 느린 학생도 한 판에 6곳을 모두 봅니다.
  빠른 학생은 상한 전에 빌런을 잡고 다음 장소로 가며, 6곳을 다 돌면 더 어려운 두 번째 바퀴가 시작됩니다.
- 생명(♥ 5개)이 다 닳아도 **탈락하지 않습니다.** 6초 동안 수리한 뒤 계속합니다(그동안 점수를 못 냅니다).
- **마지막 1분은 피버 타임**: 모든 점수가 2배입니다.
- 순위: 점수 → 포탑이 덜 부서진 학생 → 명중이 많은 학생 순.

## 자주 생기는 일

| 상황 | 해결 |
|---|---|
| QR 을 찍어도 안 열림 | 교사 PC와 태블릿이 같은 와이파이인지 확인. QR 카드 아래 "안 되면:" 주소로 시도. 방화벽 허용 확인 |
| 학생이 튕겼거나 새로고침함 | 같은 학번·이름으로 다시 들어오면 **하던 점수와 장소로** 돌아옵니다 |
| 이름을 잘못 넣음 | 새 이름으로 다시 들어오면 됩니다. 연결 끊긴 예전 이름은 교사 화면 표의 **끊김 ✕** 로 지웁니다 |
| 판 중간에 들어온 학생 | 남은 시간만큼만 참여합니다 |

## 기록 위치

`planet-turret.exe` 옆 `planet-turret-results\<날짜>\` 폴더에 판마다 파일 하나씩 저장됩니다.
교사 화면 **지난 판 기록**에서 판별로 엑셀(CSV)을 내려받을 수 있습니다.
엑셀 항목: 순위, 학번, 이름, 점수, 최고 레벨, 마지막 장소, 가 본 장소 수, 빌런·악당 격파, 포탑 부서짐, 발사, 명중, 명중률.
