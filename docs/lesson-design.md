# 수업 설계 메모

## 1. 왜 중위도 일주운동이 어려운가

| 장소 | 회전축(북극성 방향) | 지평선과 별 경로 |
|---|---|---|
| 북극 | 머리 위 수직 | 지평선과 나란히 돈다 (회전목마) |
| 적도 | 북쪽 지평선에 눕는다 | 수직으로 뜨고 진다 (물레방아) |
| 서울 | 북쪽 37.5° 높이로 비스듬함 | 모든 경로가 비스듬히 잘린다 |

교과서는 동·서·남·북 하늘 사진 네 장을 따로 외우게 한다. 실제로는 **하나의 기울어진 회전을 네 개의 창으로 본 것**인데, 그 연결을 보여 주지 않아서 어렵다.

**세 문장 규칙**
1. 축을 먼저 세운다. 축은 북극성을 향하고, 그 높이는 위도와 같다.
2. 별은 축에 수직인 원을 그린다. 꼬치에 끼운 고리를 떠올리면 된다.
3. 지평선(땅)이 그 원들을 비스듬히 자른다. 그래서 북쪽 별은 계속 보이고, 하늘의 적도 위 별은 정동에서 떠서 정서로 지며, 남쪽 별은 잠깐만 보인다.

동쪽 하늘에서 별이 떠오르는 각도는 90° − 위도로, 서울에서는 52.5°다. 중1에게는 이 계산을 묻지 않는다.

**지도 순서**: 이미 아는 두 끝(북극, 적도)에서 출발해 위도를 연속으로 바꿔 가며 보여 주고, "중위도 = 두 끝의 중간"으로 이해시킨다. 게임의 레벨 순서(북극 → 적도 → 서울 동·남·서·북)가 바로 이 흐름이다.

## 2. 1차시 수업안 (초안)

| 시간 | 단계 | 활동 |
|---|---|---|
| 0–5분 | 궁금증 만들기 | 방향 표시 없는 별 일주 사진 네 장을 보여 주고 "하늘이 네 가지로 도나?" 예상 |
| 5–12분 | 축 세우기 | 북쪽을 향해 팔을 주먹 4개 높이(약 40°)로 들어 북극성 가리키기 |
| 12–20분 | 회전목마 → 물레방아 → 서울 | 별 스티커 우산의 손잡이 각도를 90° → 0° → 37.5°로 바꾸며 돌리기 |
| 20–32분 | 사진 네 장의 정체 | 종이접시(땅) + 꼬치(축) + 모루 고리 모형을 37.5°로 꽂고, 네 방향에서 보며 사진과 방향을 짝짓기 |
| 32–40분 | 화면으로 확인 | 게임 또는 시뮬레이션으로 네 방향 확인 |
| 40–45분 | 설명 | "동쪽 하늘의 별이 비스듬히 뜨는 까닭을 축·원·땅으로 설명하기" (손짓을 하며 말하게 함) |

**주의할 점**: 방향의 기준은 항상 "동 → 서" 하나로 고정한다. 남쪽을 볼 때 왼쪽→오른쪽 움직임과 북쪽을 볼 때 시계 반대 방향 회전은 같은 움직임이다.

## 3. 검토한 아이디어와 결정

| 아이디어 | 결정 | 이유 |
|---|---|---|
| 블록 코딩(엔트리 등)으로 일주운동 구현 | 보류 | 자유도가 높고 어렵다. 빈칸 3개 버전(`prototypes/my-stellarium`)도 "너무 어렵다"는 평가 |
| Unity 구현 | 기각 | 학교 기기 사양과 설치 문제. 웹이 맞음 |
| 급강하 폭격기 롤링 게임 | 도입용으로만 가능 | 조종석 바닥이 롤 축과 항상 나란해서 **언제나 적도 관측자**가 된다(강하 각도와 무관). 바다 수평선이 화면에서 돌아서 오개념이 생길 위험 |
| **자전 행성 위 포탑 방어전** | **채택** | 땅과 지평선이 화면에 고정되고, 위도 = 축 기울기를 레벨로 바꿀 수 있음 |
| 태블릿 자이로 노출 사진 + 서버 | 보류 (후보) | 물리적으로 가장 정확함. 센서에 HTTPS가 필요하고, 나침반 보정이 필요하며, 기울인 회전판이 있어야 서울 하늘이 재현됨 |

### 태블릿 노출 사진 활동 (보류안 상세)

- 교사가 가상 공간에 별을 찍고, 학생 태블릿이 그 하늘을 비추며, 학생이 태블릿을 돌리면 노출 사진처럼 자취가 남는다.
- 손으로 자유롭게 돌리면 수평으로 돌게 돼서 북극 사진만 나온다. **다이소 회전 받침을 북쪽으로 37.5° 기울인 간이 적도의**에 태블릿을 올려야 서울 사진이 나온다. 판을 평평하게 두면 북극, 세우면 적도가 된다.
- 기술적 확인 사항: 브라우저 센서 API는 HTTPS에서만 열리는 경우가 많다(사용자 러너의 게이트웨이 터널로 해결 가능성 있음). iPad는 따로 권한을 요청해야 한다. 실내에서는 나침반이 틀어지므로 시작할 때 "북쪽 보정"을 하고 상대 회전만 쓴다.
